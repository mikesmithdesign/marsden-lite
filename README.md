# Marsden Lite — free one-page template for plumbers, heating engineers & trades

A single-file HTML template with bold navy ink, a photo hero, smooth scrolling
(Lenis) and scroll-triggered animation. No build step, no frameworks — open
`index.html` and edit.

**Live demo:** https://marsden-lite.vercel.app

## Quick start

1. Edit the text directly in `index.html` — business name, services, prices,
   recent jobs, reviews, hours and contact details.
2. Replace the photos in `img/` with your own (keep the filenames, or update
   the `src` paths).
3. Update the phone number and email — they appear in the nav, hero, contact
   band, footer and mobile call bar (`tel:` / `mailto:` links).
4. Upload anywhere — it's static files. Vercel, Netlify and GitHub Pages host
   it free.
